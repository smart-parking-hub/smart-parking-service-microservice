# Architecture Decision Records (ADR)

Mỗi quyết định quan trọng tạo file `ADR-NNN-short-title.md`.

Bắt buộc ghi:
- Status: PROPOSED / ACCEPTED / REJECTED / SUPERSEDED
- Date and owner
- Context/problem
- Constraints
- Options considered
- Decision
- Positive/negative consequences
- Security/operations/cost impact
- Migration/rollback
- Evidence/links

Các quyết định nên có ADR: tách/gộp service, chọn Kafka, Redis, DB, discovery, gateway, auth, deployment platform, consistency strategy.
